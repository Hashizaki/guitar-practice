# guitar-practice

ブラウザだけで動くギター練習アプリ（iPhone / iPad 対応）。

- **練習記録と今日のメニュー**：練習時間・連続日数・カレンダー、毎日の小さな課題（記録は端末内だけに保存）
- **音楽理論レッスン（全10回）**：音の名前からコード進行・アドリブ入門まで、音を鳴らしながら学べる初心者向けコース
- メトロノーム（テンポアップ練習つき）
- チューナー（基準音・マイク）
- コードチェンジ練習・コード判定・コード表
- 曲に合わせて弾く（定番のコード進行＋ストロークの伴奏ループ、カポ対応）
- 指板クイズ（音名を答える／場所を探す）、スケール表示
- **ギターなしでできるトレーニング**：音程当て・コード当て・リズム練習・フォーム当て

`index.html` をブラウザで開くだけで使えます。iPhone / iPad では Safari で開き、
共有 →「ホーム画面に追加」でアプリのように全画面・オフラインで使えます（https で公開した場合）。

詳しくは [HANDOFF.md](HANDOFF.md) を参照。
