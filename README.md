# guitar-practice

ブラウザだけで動く、音楽初心者向けのギター練習アプリ（iPhone / iPad 対応）。

- **練習記録と今日のメニュー**：練習時間・連続日数・カレンダー、毎日の小さな課題（記録は端末内だけに保存）
- **音楽理論レッスン（全14回）**：音の名前からコード進行・アドリブ入門、TAB譜・パワーコード・バレーコード・カポまで、音を鳴らしながら学べる
- 用語集（検索つき）
- 設定：ダーク／ライトテーマ、文字の大きさ、左利き用の表示、記録のバックアップ（書き出し・読み込み）
- メトロノーム（テンポアップ練習つき）
- チューナー（基準音・マイク）
- コードチェンジ練習・コード判定・コード表
- 曲に合わせて弾く（定番のコード進行＋ストロークの伴奏ループ、カポ対応）
- 指板クイズ（音名を答える／場所を探す）、スケール表示
- **ギターなしでできるトレーニング**：音程当て・コード当て・リズム練習・フォーム当て

音はすべてブラウザで合成しています。マイクの音声は端末内で解析するだけで、どこにも送信しません。

## 使い方

`main` に入ると GitHub Actions がビルドして GitHub Pages に公開します。
iPhone / iPad では Safari で開き、共有 →「ホーム画面に追加」でアプリのように全画面・オフラインで使えます。

初回だけ、リポジトリの **Settings → Pages → Source** を **GitHub Actions** にしてください。

## 開発

Vite + React + TypeScript。Node.js 22 以上。

```sh
npm install
npm run dev        # 開発サーバー
npm run typecheck  # 型チェック
npm test           # 単体テスト（音楽理論・リズム判定）
npm run build      # dist/ にビルド
npm run e2e        # ビルドしたものを iPhone / iPad サイズで動かす画面テスト
```

`npm run e2e` を初めて動かすときは、先に `npx playwright install chromium` が必要です。

構成と設計は [HANDOFF.md](HANDOFF.md) を参照。
